# Scripts (next iteration)

This folder will contain:

- **Model**: Script entity (id, title, body, dates).
- **UI**: script list + text editor (Notes-style).
- **Integration**: the teleprompter will show the selected script; local persistence first, then sync with backend in later iterations.

Current teleprompter text (`NotchyKeys.prompterText`) will migrate to “content of the script in display” when this module is implemented.
